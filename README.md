# Shared n8n Studio

Common **official n8n Vue editor** source customization for:
- [autonomous-investor-backend](https://github.com/lyonbegin/autonomous-investor-backend)
- [procureflow](https://github.com/lyonbegin/procureflow)

First milestone: enable blank-pane **left/middle mouse drag Pan**, preserve **Shift + left drag marquee selection**, node movement and handle connections.

This is a separate, non-production project. Original application repositories and Railway environments are not altered. Domain engines, workflows, storage, credentials and execution remain application-specific.

**Status:** source patch and isolated regression tests are available; actual patched upstream n8n deployment and user-browser acceptance are still pending.
